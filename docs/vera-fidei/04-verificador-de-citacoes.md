# Verificador De Citações

## O Que É

O verificador de citações é uma ferramenta para analisar frases atribuídas a autores católicos e comparar com o acervo indexado.

Ele ajuda a responder perguntas como:

- essa frase existe?
- foi escrita por esse autor?
- está em qual obra?
- está fora de contexto?
- é uma paráfrase?
- a tradução parece fiel?
- existe fonte primária para isso?

## Entrada Do Usuário

O usuário informa:

- citação;
- autor atribuído;
- idioma, quando aplicável.

## Saída Do Sistema

O resultado pode incluir:

- status da verificação;
- nível de confiança;
- autor encontrado;
- obra encontrada;
- trecho correspondente;
- contexto anterior;
- contexto posterior;
- referência;
- edição;
- idioma;
- tradutor, quando houver;
- explicação.

## Status Possíveis

O sistema pode classificar resultados como:

- confirmada exata;
- correspondência forte;
- tradução fiel;
- tradução imprecisa;
- paráfrase plausível;
- atribuição duvidosa;
- não encontrada.

## Limites Mensais

Cada plano possui um limite mensal de verificações.

Quando o usuário atinge o limite, o verificador bloqueia novas verificações até o próximo ciclo mensal.

O sistema informa:

- limite do plano;
- verificações usadas;
- verificações restantes;
- percentual usado;
- tempo restante para renovação do ciclo;
- mensagem de alerta.

## Alertas De Uso

O Vera.Fidei avisa o usuário quando ele atinge:

- 50% do uso mensal;
- 90% do uso mensal;
- 100% do uso mensal.

Ao atingir 100%, o usuário é orientado a aguardar a renovação mensal ou subir de plano.

## Relação Com Os Planos

Os limites atuais são:

| Plano | Limite |
|---|---:|
| Fiel | 10 verificações/mês |
| Catequista | 25 verificações/mês |
| Apologeta | 50 verificações/mês |
| Patrístico | 100 verificações/mês |
| Magistério | Ilimitado |

## Importante

O verificador é uma ferramenta de apoio. Mesmo quando encontra uma correspondência forte, o usuário deve consultar a fonte original, especialmente em trabalhos acadêmicos, publicações formais, debates públicos e materiais catequéticos.
