# Guia Do Usuário

## Criando Uma Conta

O usuário pode criar uma conta pela tela de cadastro informando:

- nome;
- e-mail;
- senha.

Depois do cadastro, o app deve abrir automaticamente a área de perfil.

## Entrando Na Conta

Na tela de login, o usuário informa e-mail e senha. Após entrar, o app direciona para o perfil ou para a página que o usuário tentou acessar.

## Perfil

A aba Perfil reúne:

- dados da conta;
- plano atual;
- favoritos;
- histórico recente de verificações;
- acesso às opções de assinatura;
- informações da conta.

O histórico foi unido à área de perfil para evitar excesso de abas no mobile.

## Biblioteca

Na Biblioteca, o usuário pode:

- navegar pelo acervo;
- buscar por obra, autor, papa, concílio, coleção, edição ou tema;
- filtrar obras com PDF;
- filtrar fontes primárias;
- filtrar obras indexadas;
- abrir fichas de obras;
- abrir PDFs vinculados.

## Abrindo Um PDF

Ao abrir um PDF, o usuário pode:

- voltar para a tela anterior;
- ir para uma página específica;
- aumentar ou diminuir zoom;
- pesquisar palavra ou trecho dentro do PDF;
- usar o visualizador no mobile/PWA.

No mobile, o visualizador foi pensado para ocupar a tela inteira e respeitar a área segura do iPhone.

## Favoritos

O usuário pode favoritar:

- obras;
- orações.

Os favoritos aparecem no perfil e servem para acompanhar leituras, referências e conteúdos que o usuário deseja consultar depois.

## Orações

A área de Orações organiza textos de oração por categorias.

O usuário pode:

- abrir categorias;
- consultar orações;
- favoritar orações;
- alternar versões quando houver mais de um idioma.

## Verificador

Na aba Verificador, o usuário informa:

- a citação;
- o autor atribuído;
- idioma, quando aplicável.

O sistema retorna um resultado com nível de confiança, explicação, referência e contexto quando encontra correspondência.

## Planos

A página de Planos mostra:

- plano gratuito;
- planos mensais;
- limite de verificações;
- benefícios;
- botão de assinatura;
- botão de gerenciamento quando existe assinatura ativa.
