## Definição curta

O Vera.Fidei é uma biblioteca católica digital com obras, documentos, PDFs, favoritos, perfil de usuário e verificador de citações. Seu objetivo é ajudar fiéis, catequistas, apologetas, pesquisadores e criadores de conteúdo a estudar a tradição da Igreja com mais fidelidade às fontes.

## Frase de apresentação

Vera.Fidei: uma biblioteca católica digital para estudar, consultar fontes primárias e verificar citações com rastreabilidade.
